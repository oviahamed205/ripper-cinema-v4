# TEST PYRAMID

```
                    /\
                   /  \
                  / E2E\
                 /------\
                /        \
               /Integration\
              /------------\
             /              \
```

Most tests are unit tests (fast, cheap, precise). Fewer integration tests. A small number of expensive, high-value E2E tests.

# PRODUCT REQUIREMENTS

## Requirement Format
Copy this block for every requirement.

```
ID: PRD-XXX
Name: [Requirement name]
Priority: P0 / P1 / P2 / P3
Description: [Description]
User: [Which user type needs this]
Expected behavior: [Behavior]

Acceptance criteria:
- [ ] ...
- [ ] ...
- [ ] ...

Dependencies:
- ...

Risks:
- ...
```

## Priority Definitions
- P0 = Critical — product does not work without it
- P1 = Important — major gap if missing
- P2 = Normal — expected but not blocking
- P3 = Nice to have — polish / future
